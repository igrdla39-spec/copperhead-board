# элктронную читалку

Ты работаешь над принципиальной схемой и печатной платой автономной электронной читалки на базе ESP32-S3 и монохромного E-Ink дисплея 4.26" 800×480 с контроллером SSD1677.

Цель проекта:
создать полностью автономную электронную читалку, где вся печатная плата расположена под E-Ink дисплеем и не выходит за его габариты.

Исходный файл KiCad может быть пустым. Если emptyboard.kicad_sch не содержит символов и проводников — это НЕ причина прекращать работу. Сам создай корректную базовую структуру схемы и добавляй функциональные блоки последовательно.

ВАЖНЫЕ ПРАВИЛА

1. Не проектируй всю схему за один шаг.
2. После каждого функционального блока:
   - сохрани .kicad_sch;
   - запусти ERC;
   - исправь ошибки;
   - только после этого переходи к следующему блоку.
3. Не придумывай распиновку микросхем.
4. Перед использованием любого GPIO ESP32-S3 проверь:
   - официальный datasheet Espressif;
   - datasheet ESP32-S3-WROOM-1;
   - strapping pins;
   - USB pins;
   - ограничения GPIO;
   - boot requirements.
5. Для E-Ink не придумывай схему питания и распиновку FPC.
   Используй официальную документацию Waveshare 4.26" B/W 800×480 SSD1677 и reference schematic именно этой панели.
6. Если есть несколько вариантов реализации — выбирай наиболее простой и надёжный для первой версии устройства.
7. Если конкретного символа нет в стандартной библиотеке KiCad — создай локальный символ или используй Generic Connector/IC с корректно подписанными выводами.
8. Не прекращай работу только из-за отсутствия готовой baseline schematic.
9. Не переходи к PCB до завершения принципиальной схемы.
10. Не разводи PCB, пока не назначены footprints и не выполнен финальный ERC.

АРХИТЕКТУРА УСТРОЙСТВА
==================================================

Основной микроконтроллер:

ESP32-S3-WROOM-1-N16R8

Используй модуль WROOM, а не голый ESP32-S3.

Требуемые функции:
- 16 MB Flash
- 8 MB PSRAM
- Wi-Fi
- Bluetooth
- native USB
- SPI для E-Ink
- SPI для microSD
- управление кнопками
- sleep modes

Питание:
- Li-Po аккумулятор 1S, 3.7 V
- ориентировочная ёмкость 1000–2000 mAh
- зарядка через USB-C
- работа устройства во время подключения USB желательна
- системная линия питания 3.3 V

Хранение книг:
- microSD

Экран:
- Waveshare / compatible 4.26" monochrome E-Ink
- 800×480
- SSD1677
- bare panel
- штатный FPC
- 24-pin ZIF connector
- pitch проверить по официальной документации панели

Управление:
- кнопка PAGE_PREV
- кнопка PAGE_NEXT
- кнопка UP
- кнопка DOWN
- кнопка OK/MENU
- при возможности отдельная POWER / WAKE

USB:
- USB-C
- зарядка
- прошивка ESP32-S3
- USB data через native USB ESP32-S3

ЭТАП 1 — ESP32-S3
==================================================

Сначала добавь только:

ESP32-S3-WROOM-1-N16R8

Добавь обязательную обвязку модуля:

- питание 3.3 V;
- decoupling capacitors;
- EN;
- reset;
- boot circuitry;
- необходимые pull-up / pull-down.

Перед подключением GPIO проверь официальную документацию Espressif.

Не назначай:
- USB pins;
- strapping pins;
- flash/PSRAM related pins;
- специальные системные выводы

на периферию без проверки.

Добавь test points минимум для:

GND
EN
BOOT

ERC

==================================================
ЭТАП 2 — USB-C
==================================================

Добавь USB-C receptacle.

USB используется как USB 2.0 device.

Подключи:

VBUS -> VBUS_5V

D+ и D- -> native USB ESP32-S3

Добавь необходимые:

- CC resistors для USB-C sink/device;
- ESD protection;
- decoupling;
- защиту VBUS при необходимости.

Не подключай USB data через внешний USB-UART, если native USB ESP32-S3 позволяет выполнить прошивку и обмен данными.

Убедись, что D+ и D- подключены именно к корректным USB GPIO ESP32-S3 согласно документации.

После этого:

ЭТАП 3 — АККУМУЛЯТОР И ЗАРЯДКА
==================================================

Предусмотри:

BAT+
GND

==================================================
ЭТАП 4 — СИСТЕМНОЕ ПИТАНИЕ 3.3 V
==================================================

От аккумулятора сформируй стабильную SYS_3V3.

Поскольку Li-Po имеет диапазон примерно от 4.2 V до области ниже 3.3 V, предпочтительно использовать buck-boost converter.

Возможный вариант:
TPS63070 или подходящий аналог.

Не копируй номиналы вслепую.

Используй datasheet выбранного DC/DC для:
- индуктивности;
- input capacitors;
- output capacitors;
- feedback network;
- enable circuitry.

Рассчитай выход строго на 3.3 V.

Учти пиковое потребление ESP32-S3 при Wi-Fi.

Добавь test point:
SYS_3V3

После этого:

SAVE
ERC

ЭТАП 5 — E-INK 4.26"
==================================================

Используется:

4.26" monochrome E-Ink
800×480
SSD1677

Используется bare panel, не готовый HAT.

Добавь 24-pin FPC/ZIF connector.

ВАЖНО:

Не назначай выводы 24-pin connector по памяти.

Найди официальный pinout именно используемой панели.

Для схемы E-Ink power section используй reference schematic Waveshare для 4.26" B/W SSD1677.

Перенеси необходимую силовую обвязку панели:
- inductor;
- diodes;
- capacitors;
- MOSFET/transistor;
- resistors;
- VGH/VGL/VSH/VSL/VCOM related circuitry

в соответствии с reference design.

Не подключай высоковольтные линии E-Ink напрямую к ESP32.

ESP32 должен взаимодействовать с дисплеем через логические линии:

EPD_SCLK
EPD_MOSI
EPD_CS
EPD_DC
EPD_RST
EPD_BUSY

и при необходимости:

EPD_PWR_EN

Логические уровни должны быть совместимы с 3.3 V.

Если level shifter не нужен — не устанавливай его.

Предусмотри возможность полностью отключать питание E-Ink после обновления изображения, если это допускается схемой reference design.

ЭТАП 9 — ФИНАЛЬНЫЙ ERC
==================================================

После сборки всех блоков:

1. Запусти полный ERC.
2. Исправь реальные ошибки.
3. Не скрывай ошибки ERC без объяснения.
4. Для каждого оставшегося warning объясни причину.
5. Проверь, что нет:
   - floating power inputs;
   - незадействованных обязательных входов;
   - конфликтующих output pins;
   - ошибочных power flags;
   - неправильных USB connections;
   - E-Ink HV nets, случайно подключённых к logic rail.

Только после этого переходи к footprints.

==================================================
ТРЕБОВАНИЯ К PCB LAYOUT
==================================================

Плата должна полностью располагаться под экраном.

Не выходить за его внешний контур без отдельного согласования.

ESP32-S3 WROOM располагай около края платы.

Антенная часть ESP32 должна:
- находиться около края корпуса;
- не иметь copper pour под antenna keepout;
- не иметь GND plane под antenna keepout;
- не находиться непосредственно над аккумулятором;
- не перекрываться металлическими деталями корпуса.

E-Ink high-voltage section размещай непосредственно рядом с FPC connector.

Минимизируй длину HV traces.

USB D+ / D- вести как differential pair в соответствии с рекомендациями Espressif/KiCad PCB stackup.

DC/DC converter:
- минимальные силовые петли;
- индуктивность и конденсаторы максимально близко к IC.

Размести аккумулятор на обратной стороне устройства либо за PCB таким образом, чтобы он не перекрывал antenna keepout.
